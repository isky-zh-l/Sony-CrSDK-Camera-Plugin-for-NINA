# 0.5.4-rc.1

程序集版本 0.5.4.0。目标 Windows x64、N.I.N.A. 3.2.0.9001、Sony Camera Remote SDK 2.02.00。本版本为发布候选，应标记为 GitHub Pre-release。

## 相较 0.4.1.3 的变化

- 按 SDK 运行时能力适配机型、曝光和 RAW 格式，使用逐帧有效尺寸与 Bayer 排列。
- 增加天文准备/恢复、参数控制面板、电量及默认关闭的实验性镜头对焦器。
- 相机、停靠页与对焦器共享协调服务；曝光等待期间可取消。移除机身对焦放大入口，预览缩放使用 N.I.N.A.。
- 修复停靠页激活及页面滚轮；退出时取消等待或重试中的连接。
- 已知可修正前置设置错误保留干净连接并提供重新检查；本地解码失败后的 Abort 不误隔离干净连接；拒绝新请求后阻止旧帧交付。
- 升级保留 settings.json 和 receiveRoot，更新完整包对应的原生批准清单，并提供安装回执回退。

## 验证与限制

维护者提供的本版本记录包含 A7M5 固件 2.00 的 7 张实拍，其中 1 张为 60 秒软件 Bulb；保存的 FITS 与收到的 RAW 独立解码逐像素一致。另有模拟集成、WPF 和安装器回归。详细范围与未测项目见 [验证说明](VALIDATION.md)。

32 型号模拟覆盖不代表真机兼容，A7RM6 离线 RAW 解码不代表该机 USB 控制通过。已完成另一台 Windows 11 x64 电脑的独立部署与基本成像验证；整夜序列、真实拔线恢复、星点效果与自动对焦精度仍不在本次验证范围。

## 异机部署与成像

同版二进制在独立 Windows 11 x64 环境配合 N.I.N.A. 3.2.0.9001、SDK 2.02.00 和 ILCE-7M5 完成安装校验、重启使用、断开重连及控制页操作。完成单张与 68 张连续 1 秒 FITS 采集，文件数量、大小、序列及已检查的曝光/ISO 头信息正常；APS-C 输出为 4624×3080、16 位、RGGB。

本次异机连续采集做了文件与元数据检查，没有逐张像素一致性核验；不能把未覆盖功能视为已经通过或已经失败。

## 安装

使用同版完整插件 ZIP，自备官方 SDK。先退出 N.I.N.A.，再按 [安装说明](INSTALL.md) 操作；不能仅替换托管 DLL。公开包不含 Sony SDK、宿主、驱动、相机照片或本机用户配置。
