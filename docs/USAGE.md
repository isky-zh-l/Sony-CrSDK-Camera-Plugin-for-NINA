# 使用与配置

## 拍摄与预览

ISO、曝光、序列、保存和 LiveView 使用 NINA 原有相机面板；额外参数在成像工作区的 **Sony CrSDK 控制** 面板中调整。参数页也可由插件或设备设置入口打开，不会自动连接或拍摄。

两种入口共享相机会话。修改相机参数需空闲并停止预览；先刷新，再提交机身提供的候选值，写入后回读。未展开的下拉框上滚轮只滚动页面。

普通快门优先匹配机身实际候选，不匹配时才检查软件 Bulb 能力。软件 Bulb 采用 1–900 秒的项目策略，不代表硬件极限。拍摄前会停止预览；取消后应等待明确终态再继续。

## 保存与默认设置

`settings.json` 位于用户数据目录 `%LOCALAPPDATA%\NINA\PluginData\9c1f3b7e-…\settings.json`（不在会被升级替换的插件目录里），保存后重连生效。默认：

```json
{"saveOriginalRaw":"never","rawCopyFolder":"raw","liveViewColor":true}
```

| 字段 | 含义 |
|---|---|
| `saveOriginalRaw: "never"` | 不额外复制 ARW，仍由 NINA 保存 FITS/XISF |
| `saveOriginalRaw: "also"` | 在输出根目录的指定子目录额外保留 ARW |
| `rawCopyFolder` | 副本子目录，默认 `raw` |
| `liveViewColor` | `true` 彩色预览，`false` 灰度预览；不改变 RAW 像素 |

旧 `only` 模式可能遇到宿主 ARW6 缩略图问题，不推荐使用。界面保存默认值仅影响下次连接，与立即调整机身参数不同。`never` 不删除卡内照片或已有副本；中转文件的清理规则见下节。

## 接收缓存与清理

相机下载的 ARW 先落在用户数据目录的中转文件夹（`%LOCALAPPDATA%\NINA\PluginData\9c1f3b7e-…\receive\capture-…`），只用于当前帧解码：

| 情况 | 行为 |
|---|---|
| 交付成功，`saveOriginalRaw: "also"` | 先复制到 NINA 输出目录下的 `raw`（可配置）子目录，再删除中转目录内本插件写入的 ARW |
| 交付成功，`saveOriginalRaw: "never"` | 不保留副本，直接删除中转 ARW |
| `saveOriginalRaw: "only"` | ARW 作为原图交给 NINA，交付后同样删除中转副本（NINA 已持有数据） |
| 解码或交付失败 | 保留中转文件便于排查，不自动清理；日志和提示给出路径，确认后可手动删除对应 `capture-*` 目录 |
| 清理本身失败 | 保留并记入日志，不重试删除 NINA 图像目录或卡内文件 |

清理只作用于 `receive` 下由插件创建的 `capture-*` 目录，且仅在目录已空时删除该目录；拒绝跟随符号链接或重解析点，也不会改动 NINA 的图像保存目录。

## 天文准备与恢复

天文准备可按实际能力设置长曝降噪、防抖、手动对焦及全尺寸无损压缩档；默认不启用。先核对所有请求，再写入并保存同一连接的回执。选择全尺寸无损压缩不会自动关闭 APS-C 裁切。

恢复只接受当前干净连接的回执，不覆盖后续手动改动。断开不会自动恢复机身；需要时在断开前显式恢复。部分写入失败会保留回执，未确认状态不能当作成功。

## 错误处理

已知可修正的拍摄前条件不满足时，可保留干净连接并显示修正提示。改正后点击 **重新检查** 或重新发起拍摄，不会自动补拍或恢复原序列。

本地解码失败不交付坏图，原片可用于排查；SDK/USB 故障、未确认写入或释放失败仍需按提示恢复或重连。新请求被拒绝后不会交付旧帧，也不会从卡内盲选最后一张补传。

**边界行为（有意设计）**：连接阶段或拍摄前的可纠正条件（M、MF、仅 RAW、Single）会保持连接并显示修正提示；但如果相机在快门前最后一刻改了 ISO，或画幅条件在最终核对时变化，原生层会拒绝触发快门并把本次会话标为未确认——此时需要断开重连，不会带着不确定状态硬拍。取舍是"宁可不拍，也不交付错帧"。

## 可选电子镜头对焦器

设置 `enableLensFocuser: true` 并重连相机后，可选择 **Sony CrSDK Lens Focus (experimental)**。它共享相机会话，要求电子镜头、MF、可写位置及驱动状态回读；望远镜直焦不提供虚构镜头能力。

位置是 SDK 单位，未知物理步长和温度不伪造。绝对移动没有已验证的中途停止，自动对焦精度需另行用星点验证；默认关闭。断开或重连相机后需重新连接对焦器。

## 界面语言与画幅提醒

插件设置提供“自动／中文／English”。默认自动跟随当前 NINA 配置的界面语言；中文环境使用中文，其他语言回退英文。保存后保留选择。切换语言不更改机身设置；型号、技术标识和日志错误码保留原样。

相机面板持续显示“全画幅／APS-C／未知”。默认允许 APS-C／Super 35 拍摄；首次检测到裁切或画幅状态变化时显示非模态提醒，连续同状态曝光不重复提醒。请检查实际图像尺寸、视场及解算配置。

启用并保存“要求全画幅”后，下次连接应用该设置；检测到裁切或无法可靠确认全画幅时，在曝光前拒绝请求。机身模式是主要依据，RAW 校验必须结合当前机型与格式，不能只按宽高判定。机身与 RAW 证据冲突时保留未知，重复读取相同机身属性不会解除冲突；新的匹配 RAW 或机身模式变化后重新评估。
