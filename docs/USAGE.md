# 使用与配置

## 拍摄与预览

ISO、曝光、序列、保存和 LiveView 使用 NINA 原有相机面板；额外参数在成像工作区的 **Sony CrSDK 控制** 面板中调整。参数页也可由插件或设备设置入口打开，不会自动连接或拍摄。

两种入口共享相机会话。修改相机参数需空闲并停止预览；先刷新，再提交机身提供的候选值，写入后回读。未展开的下拉框上滚轮只滚动页面。

普通快门优先匹配机身实际候选，不匹配时才检查软件 Bulb 能力。软件 Bulb 采用 1–900 秒的项目策略，不代表硬件极限。拍摄前会停止预览；取消后应等待明确终态再继续。

## 保存与默认设置

`settings.json` 位于插件目录，重连生效。默认：

```json
{"saveOriginalRaw":"never","rawCopyFolder":"raw","liveViewColor":true}
```

| 字段 | 含义 |
|---|---|
| `saveOriginalRaw: "never"` | 不额外复制 ARW，仍由 NINA 保存 FITS/XISF |
| `saveOriginalRaw: "also"` | 在输出根目录的指定子目录额外保留 ARW |
| `rawCopyFolder` | 副本子目录，默认 `raw` |
| `liveViewColor` | `true` 彩色预览，`false` 灰度预览；不改变 RAW 像素 |

旧 `only` 模式可能遇到宿主 ARW6 缩略图问题，不推荐使用。`never` 不删除卡内照片、已有副本或 SDK 临时接收文件。界面保存默认值仅影响下次连接，与立即调整机身参数不同。

## 天文准备与恢复

天文准备可按实际能力设置长曝降噪、防抖、手动对焦及全尺寸无损压缩档；默认不启用。先核对所有请求，再写入并保存同一连接的回执。选择全尺寸无损压缩不会自动关闭 APS-C 裁切。

恢复只接受当前干净连接的回执，不覆盖后续手动改动。断开不会自动恢复机身；需要时在断开前显式恢复。部分写入失败会保留回执，未确认状态不能当作成功。

## 错误处理

已知可修正的拍摄前条件不满足时，可保留干净连接并显示修正提示。改正后点击 **重新检查** 或重新发起拍摄，不会自动补拍或恢复原序列。

本地解码失败不交付坏图，原片可用于排查；SDK/USB 故障、未确认写入或释放失败仍需按提示恢复或重连。新请求被拒绝后不会交付旧帧，也不会从卡内盲选最后一张补传。

## 可选电子镜头对焦器

设置 `enableLensFocuser: true` 并重连相机后，可选择 **Sony CrSDK Lens Focus (experimental)**。它共享相机会话，要求电子镜头、MF、可写位置及驱动状态回读；望远镜直焦不提供虚构镜头能力。

位置是 SDK 单位，未知物理步长和温度不伪造。绝对移动没有已验证的中途停止，自动对焦精度需另行用星点验证；默认关闭。断开或重连相机后需重新连接对焦器。
