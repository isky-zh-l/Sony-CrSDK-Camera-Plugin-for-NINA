# NINA 天文参数界面：0.5.4-rc.1

![Sony CrSDK 控制面板](images/sony-controls.png)

在 NINA 成像工作区的工具面板列表选择 Sony CrSDK 控制，或在插件选项及相机/镜头对焦器的设置入口打开。只有点击刷新后读取 SDK 属性，打开界面不会自动连接或拍摄。界面提供相机参数、天文准备、默认设置三个页签。

NINA 已有的 ISO、曝光、拍摄、实时预览、电量以及可选镜头对焦位置使用 NINA 原有面板。没有统一相机接口的光圈、RAW 压缩、降噪、防抖、对焦模式、快门、静音、APS-C、预览效果/画质、存储位置及卡槽余量由插件界面显示。只列出机身真实候选；未知值、缺失能力、只读值不能被写入。

修改参数需空闲并停止实时预览，应用前核对连接和当前值，写入后读回。机身菜单改变后先重新刷新。机身对焦放大入口已取消，图像放大使用 NINA 的电脑预览。

天文准备先检查全部所选能力，再应用并保存本连接回执。部分失败保留回执与错误，不能宣称全部成功。恢复不会覆盖后续机身手动改动，也不能跨连接使用旧回执。回执中已提交的参数需先恢复，再单项修改。

保存默认设置仅影响下次连接；立即准备与保存默认值是独立操作。自动准备需明确勾选并保存。配置保留未知字段，保存生成 settings.json.bak，发现并发编辑拒绝覆盖。部署的原生哈希批准不由界面修改。

镜头对焦器仍是可选实验功能。无电子镜头不提供位置和光圈能力；绝对移动没有已验证的中途停止，不据此承诺天文自动对焦效果。温度、制冷、自动遮光等没有可验证依据的能力不虚构。

## 验证与操作边界

`tests/SettingsUi` 验证 WPF 假会话、配置保存和页面行为，不加载 SDK。`tools/Test-MultiCamera.ps1` 使用隔离替身。实机结果与复现入口见 [验证说明](VALIDATION.md)。公开仓库不依赖本机维护启动脚本或私有隔离钩子。

滚轮停在未展开的下拉框或文本框上时滚动页面，不改变参数；展开的下拉列表仍正常滚动。架构与操作协调见 [三层架构说明](ARCHITECTURE.md)。

已知可修正的拍摄设置问题会显示“已连接，等待修正设置”。改正后点击“重新检查”或重试；不自动重拍。本地解码失败不会仅因宿主取消清理而使干净连接失效；真正的原生未确认状态仍需恢复或重连。见 [恢复说明](RECOVERY.md)。
