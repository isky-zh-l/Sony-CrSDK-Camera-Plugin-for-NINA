# 保留连接与重新检查（0.5.4-rc.1）

相机已完成 SDK 连接且能读取必要参数时，MF、M 手动曝光、仅 RAW、有效 RAW 压缩等已知可修正条件不满足，不再立即断开。面板显示“已连接，等待修正设置”和具体提示；用户可在机身或面板改正，再点击“重新检查”或重试拍摄。不会自动触发下一次曝光，也不承诺自动恢复原序列。

拍摄提交前先检查这些条件，再改 ISO/快门，尽量在快门触发前拒绝无效请求。NINA 在错误后调用 Abort 时，如果没有进行中的原生拍摄且客户端仍是干净连接，不再对已结束任务执行无意义的 cancel/reconcile。因此本地解码失败不会仅因宿主清理动作把好连接隔离。

真实 USB/SDK 错误、未确认的原生写入或拍摄、释放/恢复失败，仍保持未确认状态处理；不假装相机可用。必要时仍需停止操作并重新连接。缺失必要能力或参数不可读的连接失败，不按普通模式设置问题处理。

本地处理失败不交付坏图，接收的原片保留用于排查。纠正后应重新拍摄；重新检查不会把同一张失败原片变为成功。正常的手动断开保持不变。

恢复行为的已记录结果与实机检查清单见 [验证说明](VALIDATION.md)。
