# 0.4.1-dev 最终验证记录

本文件是待填写清单，不代表以下测试已经通过。0.4.0 的历史真机结果见根 README；其私人照片和日志不纳入仓库。

可先执行不连接相机的配置/预览回归：

```powershell
dotnet run --project .\tests\SettingsPreview\SettingsPreview.csproj -c Release '-p:NinaApp=<NINA目录>'
```

该程序使用合成 JPEG 验证彩色/灰度分支和 settings.json，不初始化 Sony SDK。

连接失败恢复回归（只使用隔离 TEST 后端，不访问真实相机）：先构建本项目并准备本地部署目录，然后执行：

```powershell
.\tools\Test-ConnectionRecovery.ps1 -NinaApp '<NINA目录>' -LocalDeployment '<本地部署目录>'
```

该回归模拟非 M 档与非 MF 条件，验证两次失败后同一客户端仍能连接、断开、重连。测试允许 TEST 包的入口仅存在于独立测试程序，不改变正式插件的校验规则。

记录 Windows、NINA、SDK、机身固件、RAW 格式、USB 控制器及本次插件/包装/解码器 DLL 的 SHA256。以实际封装产物进行验证。
