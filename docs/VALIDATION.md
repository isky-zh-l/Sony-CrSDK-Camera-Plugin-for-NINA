# 验证范围

当前版本：0.5.4-rc.1，程序集 0.5.4.0。目标 Windows x64、N.I.N.A. 3.2.0.9001 与 Sony Camera Remote SDK 2.02.00。以下结论按实际验证环境和功能区分，不代表所有机型、固件或模式均兼容。

## 异机部署与基本成像（2026-10-25）

在独立于开发环境的另一台 Windows 11 x64 电脑上，Sony ILCE-7M5 通过 USB PC Remote 完成：

- 发行包与 SDK 校验、安装前检查、完整安装及插件加载。
- 多次正常退出/重启 N.I.N.A. 后继续使用，相机识别、参数读取、断开及同进程重连。
- 1 秒单张与 68 张连续 1 秒 FITS 采集。文件数量、大小、序列连续性和已检查的头信息正常，无空文件。
- APS-C 模式下输出 4624×3080、16 位容器、RGGB；已检查的曝光时间和 ISO 与拍摄设置一致。
- Sony 扩展控制页显示、参数读取/回读及页面滚轮；未展开的下拉框不会因滚轮误改值。

本次没有修改发行包 DLL、放宽校验或使用模拟 SDK。这确认独立部署及基本成像链路可用，连续文件检查不等同于逐张像素核验或整夜稳定性验收。

## 既有本机验证

ILCE-7M5 固件 2.00 的两套同机宿主环境共 7 张实拍，包括三种 RAW 档的短曝和一张 60 秒软件 Bulb。7 张 7028×4688 RGGB FITS 的传感器样本与对应 RAW 独立解码逐像素一致。该结论属于上述 7 张，不套用于异机的 68 张连续采集。

已有记录还覆盖取消后的恢复、断开重连、彩色/灰度 LiveView、可纠正错误后保留连接与重新检查、阻止旧帧交付，以及部分天文参数准备/恢复。USB 供电时没有有效电量读数，界面不虚构数值。

离线回归记录包含 553 个集成断言、47 个 UI 断言和 9 个安装器案例。32 型号为模拟覆盖，19 个真实 RAW 夹具使用模拟传输；都不能代替其他机型的 USB 验收。A7RM6 的离线解码结果不代表其控制链路已经实测。

## 仍未覆盖的范围

异机环境未完整重测 RAW 格式矩阵、ARW 副本及卡内原片比较、Bulb/取消、LiveView 色彩切换、主动构造错误恢复、天文准备/恢复、物理拔插、整夜运行、镜头对焦器和卸载回退。这些未覆盖项不等于发现故障，也不否定独立部署与基本成像通过。

其他机型、固件与输出模式应分别建立验证记录。APS-C 与全幅等不同 RAW 几何不能混用校准结论；自动对焦精度还需星点验证。

## 开发者离线检查入口

`tests/SettingsPreview` 和 `tests/SettingsUi` 检查配置与 WPF 行为；`tools/Test-MultiCamera.ps1` 检查替身后端及图像交付；`tests/test_real_raw.py` 检查固定 RAW 夹具解码。真实样本来源/哈希保存在 `config/real-raw-corpus.json`，原片不随仓库分发。构建或这些离线检查通过，不构成额外实机验收。
