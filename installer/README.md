# Sony CrSDK Camera Plugin for N.I.N.A.

正式版 **0.5.4**，程序集 **0.5.4.0**。

1. 按 [安装教程](../docs/INSTALL.md) 准备指定 NINA、VC++ 运行库和自行取得的 Sony SDK。
2. 退出 NINA，在本目录运行 Install.ps1；建议先使用 -ValidateOnly。
3. 连接相机后先完成一张短曝光；设置与兼容范围见 [使用说明](../docs/USAGE.md) 和 [兼容性](../docs/COMPATIBILITY.md)。

目录内 corresponding-source.zip 为对应项目与 LibRaw 源码；许可和重建信息见 SOURCE.md。公开包不含 Sony SDK、宿主、驱动或照片。

安装包沿用已验证构建，界面版本可能仍显示 `0.5.4-rc.1`。
