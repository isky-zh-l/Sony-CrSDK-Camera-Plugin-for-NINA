# 通用相机接口与能力边界

C++ 包装层和通用 C# 客户端提供共享的相机控制接口；下层存在接口，不代表 N.I.N.A. 已为所有能力提供用户流程。插件用户功能及实测范围以根 README、docs/ASTRO_FEATURES.md 和 docs/VALIDATION.md 为准。

## 接口组织

- Core ABI 2 提供发现、连接、参数、曝光、取消和恢复；Feature ABI 1 提供属性能力、LiveView、镜头、存储及内容访问。布局和入口在公开头文件、Native.cs 与 Native.Features.cs 中核对。
- SDK 类型和属性码封装在 C++ 内部。C# 使用项目模型，通过单 owner 线程调用原生层，不依赖 N.I.N.A. 或 WPF。
- 属性的存在、可读/可写状态、候选值和范围来自当前机身；候选不能跨连接或机型盲用。写入需回读，未确认操作不能当作成功。

## 能力

| 接口 | 边界 |
|---|---|
| ISO、普通快门、软件 Bulb、完整 RAW | 根据当前相机候选与能力选择，受拍摄前置检查、取消及恢复状态约束 |
| JPEG LiveView | 按需拉帧，不等同传感器 RAW 或科学视频；进入曝光前停止预览 |
| 光圈、RAW、降噪、防抖、拍摄与存储设置 | 按实际候选和回读处理；不据 SDK 型号清单保证所有属性可用 |
| 电量和卡状态 | 未知或非百分比读数不伪造；SDK 过热阈值不是实时传感器温度 |
| 镜头位置与驱动状态 | 电子镜头和当前能力是前提；绝对移动停止与自动对焦精度不作未经验证的承诺 |
| 录像和卡内内容访问 | 下层提供独立接口，不等于 N.I.N.A. 已实现视频工作流；内容连接不盲补未知归属帧 |

历史对焦放大属性编号为 ABI 兼容保留，产品 UI 已移除，写入不提供未经验证的坐标协议。实际映射见 feature-property-support.json、sony_features.h 和 Native.Features.cs。

## 构建与验证

使用仓库根 build.ps1 构建完整组件；SDK 由使用者另行获取。不要将重新编译的库混入旧批准包，保留哈希、ABI、源码锁和隔离测试后端要求。通用客户端可被独立工具复用，运行独立工具时不能与宿主同时占用实体相机。

模拟测试、真实 RAW 文件解码、宿主界面与 USB 实拍是不同验证范围；报告结果时分别说明。项目不提供硬件 binning、RAW ROI、制冷或其他没有可靠依据的相机能力。
